# MG4
## Devlog
The FLoatAnimation script makes the fish food bob up and down by using Update() to move the object. The _up variable determines whether the object is currently moving up or down, while _timer measures how long it has been moving in that direction. The Start() method initializes these values, and the cycle repeats to create a continuous floating animation.
